01 / DIRECTION

设计方向与主张

面向"企业贷款咨询"的 B 端/小程序产品：用户要的是信任感（钱的事不能轻浮）与清晰高效（高频作业）。墨金方向用深墨蓝建立专业信任，用克制的暖金做唯一强调色，避免蓝紫渐变、奶油赤陶、酸性绿等被滥用的默认审美。

◆ 核心气质

沉稳 · 专业 · 有重量感。像一家靠谱的融资顾问事务所，而不是花哨的互金 App。

信任 专业 Premium

◆ 与现状的关系

保留你原有的"墨蓝主色"基因（Web 的 #0b1220 暗底 / Mini 的 --brand-navy），但把混乱的蓝色 + 散落灰、emoji 式处理，收敛为墨蓝 + 单一暖金的二元体系，并打通双端令牌。

03 / ORIGINAL ICON LIBRARY

原创 SVG 图标库

收敛 Web 三套来源 + 对齐 Mini 单套实现，统一为 24×24 viewBox、stroke 1.75、圆角端点、currentColor 的线性图标。覆盖双端业务所需，命名语义化、可复用。

着色机制（修复你最大的痛点）： Web 端沿用现有 AppIcon 已支持的 var() 着色；Mini 端因小程序 SVG stroke 不解析 var()，改为运行时按当前主题注入真实色值生成 data-URI，让 TabBar / 列表图标随换肤联动，不再写死 #2443C2。所有内联散落 SVG 全部回收进统一组件。
