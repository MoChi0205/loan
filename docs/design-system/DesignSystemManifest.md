# DesignSystemManifest · 墨金 Ink & Gold

> 贷款咨询系统前端（Web 管理端 / 小程序）统一设计系统。本文档为交付基线，组件规范见 `ComponentSpec.md`，图标组件代码见 `code/`，可交互原型见 `prototype/design-showcase.html`。

## 1. 设计原则
- **信任优先**：金融场景，墨蓝承载专业与稳重，暖金仅作价值/行动强调，不滥用。
- **二元克制**：全系统仅「墨蓝 + 暖金」两族主色 + 中性灰阶 + 三态语义色，杜绝多色噪点。
- **跨端同源**：一套语义令牌同时映射 Web（暗色为主）与 Mini（浅色为主），消除 `--loan-*` / `--brand-*` 双份维护。
- **图标单一来源**：36 枚原创 SVG 图标，几何规范统一，Web/Mini 共用 `icons.js`。

## 3. 字体
| 角色 | 字体 | 备注 |
|---|---|---|
| Display / 标题 | Space Grotesk + Noto Sans SC 900/700 | 刻意避开 Inter/Roboto/Arial 默认字体 |
| Body / 正文 | Noto Sans SC 400/500 | 中文优先 |
| 数据 / 金额 | Space Grotesk（等宽感） | 数字与金额对齐 |

## 4. 间距标尺（4px 基数）
`--sp-1:4` `--sp-2:8` `--sp-3:12` `--sp-4:16` `--sp-6:24` `--sp-8:32` `--sp-12:48`
组件内外边距、栅格 gap 一律取自标尺，禁止魔法数。

## 5. 圆角
`--r-sm:8` `--r-md:12` `--r-lg:16` `--r-pill:999`
- 控件/小卡片 8；面板/大卡片 12–16；全圆角标签/按钮 999。

## 6. 阴影 /  elevation
`--sh-sm:0 1px 2px /.06,0 1px 3px /.08`
`--sh-md:0 4px 14px /.10`
`--sh-lg:0 12px 32px /.16`
暗主题下阴影减弱或改用描边分区。

## 7. 动效
- 过渡时长 `0.2–0.3s`；悬停位移 `translateY(-3px)` 仅用于卡片类。
- 尊重 `prefers-reduced-motion`：减少/关闭非必要动画。

## 8. 图标规范
- viewBox `0 0 24 24`，`stroke-width 1.75`，`stroke-linecap/linejoin: round`，`fill: none`。
- 视觉键线（optical square）对齐 24 格，正负形留白一致。
- **着色**：Web 经 `AppIcon` 透传 `stroke`，默认 `currentColor` 可接 `var()`；Mini 经 `AppIcon` 运行时注入真实色（见 `code/AppIcon.mini.vue`）。
- 禁止 emoji 图标、禁止字体图标混用、禁止散落内联 `<svg>`（统一收敛进 `AppIcon`）。

## 9. 断点与栅格
- Web：≥1280 桌面（侧栏 228px + 主区）；≥768 平板（侧栏可收起）；<768 移动（抽屉）。
- Mini：以 `rpx` 适配，设计基准 375。
