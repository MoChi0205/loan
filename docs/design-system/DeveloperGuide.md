# 前端设计系统开发指南

## 当前实现入口

| 端 | 主题 | 图标 | 全局样式 |
|---|---|---|---|
| Web | `loan-web/src/theme/index.js` | `loan-web/src/components/AppIcon.vue`、`icons.js` | `loan-web/src/styles/index.css` |
| H5 / 小程序 | `loan-mini/theme.js` | `loan-mini/components/AppIcon.vue` | `loan-mini/App.vue` |

文档不保存组件代码副本；修改以上源码后同步更新规范，避免两份实现漂移。

## 开发规则

1. 颜色、背景、文字、边框和状态优先使用现有语义变量；新增主题值必须同时定义明暗映射。
2. 图标统一通过 `AppIcon` 使用。Web 可传 `currentColor` 或 CSS 变量；小程序 SVG 必须在运行时注入真实色值。
3. 表单、抽屉、下拉框和弹窗必须同时验证明暗主题、窄屏、滚动、遮罩与键盘操作。
4. 子菜单使用独立路由；页面内页签只用于同一路由内确有共同上下文的数据切换。
5. 尊重 `prefers-reduced-motion`，折叠、换肤和页面过渡不应影响信息读取或操作结果。

## 验收

- 主题切换后正文、卡片、弹层、遮罩、表格、下拉框和图标无透底、叠影或低对比。
- 搜索下拉不超出可视区域，输入有防抖，加载和空结果状态清晰。
- 业务枚举显示中文，内部编码和业务 ID 不作为页面文本显示。
- Web、H5 和小程序的同类组件交互一致，且生产构建通过。
