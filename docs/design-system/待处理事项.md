## 四、验收标准

1. **令牌单一来源**：换肤时仅修改一处令牌定义，双端（及图标）同步变化。
2. **图标统一**：全部业务图标来自 `code/icons.js` 单一来源，统一 24×24、线宽 1.75、圆角端点、`currentColor` 着色；Web 随 `var()` 联动，Mini 随 THEME 注入联动。
3. **无硬编码颜色**：`loan-web/src/styles/index.css` 与 `loan-mini` 全局样式中不再出现游离 hex（令牌未覆盖的极少特例需注释说明）。
4. **零回归**：原有功能、路由、接口不受影响；构建通过、无控制台报错。

## 五、关键风险与注意事项

- **index.css 体积大**：1157 行含大量重复硬编码，建议增量替换 + 全局搜索游离 hex，避免一次性大改引入回归。
- **Mini var() 陷阱**：小程序 SVG `stroke` 不解析 `var()`，必须用真实色值注入（见 `AppIcon.mini.vue` 的 THEME 方案），切勿直接复用 Web 的 `var()` 写法。
- **图标名映射**：`DeveloperGuide.md` 提供旧图标名 → 新 `AppIcon` 名映射，迁移时对照使用，避免漏改。
- **分阶段提交**：建议 A/B/C 三段分别提 PR，便于 review 与回滚。
