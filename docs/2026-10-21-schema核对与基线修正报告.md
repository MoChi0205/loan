## 四、纪律（已写入 skills）

- **`db/loan-db-schema.sql` 不是真理，生产库才是**。文档可能与线上结构性偏差。
- 往任何表 insert 前，先跑核对脚本看目标表的 NOT NULL 无默认列；MyBatis-Plus 默认跳过 null 字段，
  漏设即运行时报错。
- 新增表 / 加列 / 改可空性后，必须重新生成 schema 基线并提交。
- 语义可空但生产 NOT NULL 的列，代码显式写空串占位，并同步把查询条件改成
  `IS NULL OR = ''`（两处必须同时改：只改 insert 会重复插入，只改查询照样报错）。
