## 2. 角色、菜单、按钮权限矩阵

| 用例 | 角色/端 | 操作 | 预期 |
|---|---|---|---|
| AUTH-001 | 全角色/Web | 手机号+验证码登录、账号密码+验证码登录、退出 | 登录成功；退出后 token 失效；验证码随机字母数字且错误/过期拒绝 |
| AUTH-002 | 全角色/Web | 找回密码入口、错误手机号、验证码重放 | Web 支持找回；错误/重放拒绝；日志不含手机号明文/token |
| AUTH-003 | 客户/小程序 | 一键登录、验证码登录 | 仅客户端流程；不出现密码找回；会话与 Web 客户身份可关联 |
| MENU-001 | 顾问 | 工作台、我的线索、我的客户、服务台、我的申请 | 仅本人数据；无部门/全司审批菜单 |
| MENU-002 | 部门经理 | 工作台、团队客户、审批中心、我的审批 | 本部门数据；可审批可见范围内外出/超限手机号申请 |
| MENU-003 | 运营 | 工作台、审批、客户 | 按实际授权范围；管理角色可审批授权范围，不越界 |
| MENU-004 | 老板/超管 | 全部内部菜单、审批 | 全公司数据；可直接查看手机号；渠道菜单排除 |
| MENU-005 | 渠道 | 登录后菜单树、直达内部路由 | 不返回内部服务台、审批、员工客户、内部报告菜单；直达返回 403 |
| MENU-006 | 任一角色 | 无模块权限时加载菜单 | 不显示空父级菜单；不存在“仅父级无子菜单”的残留权限 |
| BTN-001 | 顾问 | 创建线索、创建预约、提交跟进 | 成功；仅写入本人范围；重复提交幂等 |
| BTN-002 | 经理 | 审批通过/驳回、批量操作 | 仅处理本部门可见申请；二次提交被拒绝 |
| BTN-003 | 老板/超管 | 直接查看手机号 | 无审批；记录查看次数/审计事件 |
| BTN-004 | 顾问 | 首次客户解锁次数范围内查看手机号 | 无审批；显示脱敏或受控明文；超过阈值创建审批 |
| BTN-005 | 经理 | 审批顾问超限手机号 | 审批后顾问获得一次受控查看；经理超限转老板/超管 |
| BTN-006 | 全角色 | 导出、下载、删除、分配 | 按按钮权限；客户端不返回业务 ID、phone_plain、银行准入规则 |

## 3. 认证、网关与会话

| 用例 | 步骤 | 预期 |
|---|---|---|

## 10. 对立面安全测试

1. 顾问读取其他顾问客户、经理读取其他部门客户、渠道读取内部菜单和接口，均应 403 或空数据。
2. 伪造 `ownerStaffCode`、`deptCode`、`roleCode`、`X-Internal-Token`、clientType，均不得改变服务端数据范围。
3. 响应、日志、异常、下载文件不得出现 `phone_plain`、AES 密文、JWT、Nacos 密码、OSS 密钥、银行准入规则或内部业务 ID。
4. 模糊搜索 `%`、`_`、超长 Unicode、SQL/JSON 注入、重复请求、断网重试均应安全处理。
5. 网关拒绝响应只能写一次；所有错误使用统一结构和 traceId，不能返回 Java 堆栈。

## 11. 失败判定与证据

- P0：越权、手机号明文泄露、跨端权限扩大、重复写响应导致请求失败、数据库写入错乱。
- P1：核心流程不可用、菜单错误、审批状态错误、报告视角混淆、p95 超标。
- P2：提示文案、布局、非核心筛选、可访问性问题。
- 每条用例记录：请求/响应摘要、角色、端、时间、traceId、数据库只读查询、截图或日志路径。

关联联动顺序：

1. 线索创建/认领 → 客户档案与我的客户 → 客户跟进/画像/回放。
2. 客户档案 → 创建预约 → 到店/开始/完成或改期/取消 → 工作台和通知。
3. 外出申请 → 经理/老板审批 → 出发打卡（照片+单点位置）→ 返回打卡 → 服务台回放。
4. 客户材料/OCR → 风险分析报告 → 客户视角与员工内部聚合视角隔离。
5. 敏感手机号查看 → 次数累计 → 超限审批 → 通知铃铛 → 受控解锁与审计。
