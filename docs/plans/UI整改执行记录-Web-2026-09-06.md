## 一、整改清单（Web `/normalize`）

### 1. 补齐缺失的语义柔和色令牌（修复暗色模式对比度 bug）
原 `--loan-warning-bg/-line/-text` 在 `ScreeningReport.vue:284-288` 与 `Layout.vue:725-726` 被引用，但 `styles/index.css` 与 `theme/index.js` **均未定义** → 暗色模式下回退浅奶油色（如 `#fffbeb`），在深色卡片上产生对比度错误。新增完整"语义柔和色"集合（success/warning/danger/info 的 bg/line/text），并补齐"分类强调色"（cat-indigo/teal/orange/purple）供仪表盘多指标区分。

| 文件 | 改动 |
|---|---|
| `src/styles/index.css:37` 后 | 新增 `--loan-*-bg/-line/-text`（暗色低透明叠加值）+ `--loan-cat-*`（暗色值）作为 `:root` 兜底（与文件既有的暗色默认值约定一致） |
| `src/theme/index.js:112` 后（`applyVars`） | 新增同上 16 个令牌，按 `isDark` 输出暗/浅双值，随主题切换实时生效 |

> 双端均落地后：`ScreeningReport` 警示块与 `Layout` 顶部提示条在暗/浅模式下均使用正确语义色，不再依赖裸 hex 回退。

### 2. 令牌化 Overview 统计卡调色板（DOM 裸 hex → 变量）
`Overview.vue:13` 以 `:style="{ '--accent': card.color }"` 将 `color` 注入为 CSS 变量（DOM 上下文，`var()` 可用），原 8 项裸 hex 改为令牌引用：

| 原（裸 hex） | 改为（令牌） |
|---|---|
| `#3b82f6` client | `var(--loan-primary)` |
| `#6366f1` lead | `var(--loan-cat-indigo)` |
| `#14b8a6` order | `var(--loan-cat-teal)` |
| `#22c55e` deal | `var(--loan-success)` |
| `#10b981` dealAmount | `var(--loan-success)` |
| `#f59e0b` reward | `var(--loan-warning)` |
| `#f97316` rewardAmount | `var(--loan-cat-orange)` |
| `#a855f7` screening | `var(--loan-cat-purple)` |

### 3. 令牌化 Overview 增量色调（裸 rgba → 语义柔和色）
| 文件:行 | 原 | 改 |
|---|---|---|
| `Overview.vue:289-290` | `background: rgba(52,211,153,0.14)` / `rgba(248,113,113,0.14)` | `var(--loan-success-bg)` / `var(--loan-danger-bg)`（复用新增令牌，明暗自适应） |

## 三、回归与风险

1. **嵌套 CSS 变量**：`card.color` 现在值为 `var(--loan-primary)` 等，经 `:style="{'--accent': card.color}"` 再被 `var(--accent)` 消费——CSS 嵌套变量合法，渲染等价。
2. **新增令牌仅"追加"**：未改动任何既有令牌取值与组件既有样式，旧 `var(--loan-*, #fallback)` 写法因变量现已定义而自然走变量，回退值成为纯兜底（无害）。
3. **未执行构建/可视化回归**：改动为纯 CSS 变量声明 + 字符串字面量替换，语法已校验；建议视觉走查暗/浅双主题确认警示块与统计卡配色符合预期（同小程序端，本轮未跑 `vite build`）。
