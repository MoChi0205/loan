本稿设计要点（请逐项审核）
  • ① 三端信息架构统一：管理端「分组侧栏 + 多标签页 + 角色化工作台」；移动端「自绘 TabBar(角色化) + Hero 页头 + 卡片流」，首页/客户/我的 三级清晰。
  • ② 角色化工作台：顾问看「我的客户/待跟进/待审批/本月成交」；经理看「团队指标/待分配」；渠道看「我录线索」；老板看「全局经营」。顶部角色切换可对比。
  • ③ 审批零单号（D68 红线）：所有审批条目只显示「提交人 + 事项 + 状态 + 时间」，不出现任何 papr/线索/工单编号。
  • ④ 空状态与反馈统一：列表空、加载失败均用统一插画 + 引导操作，不再留白块/白屏。
  • ⑤ 配色体系双端独立：Web 维持企业暗色（#0b1220/#3b82f6）；移动维持冷玻璃深蓝（#2443C2 + 暖金 #FFB020），两端品牌色不互用。
  • ⑥ 全局命令搜索（⌘K）：管理端新增命令面板入口，移动端顶部搜索，提升多角色高频操作效率。
