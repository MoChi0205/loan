v2 移动端改了什么（请逐项审核）
  • ① 去 AI 味 / 金融咨询调性：弃用「智能匹配 / 匹配度 / 秒级」等 AI 话术与冷玻璃质感；改为墨蓝+香槟金的高端顾问感，暖象牙卡片、沉稳宝蓝主操作，像「企融顾问服务台」而非工具。
  • ② 图标整体重做：统一双色实心 chip（圆角 13px + 1.8 描边）+ TabBar 实心激活态；新增 search / filter(滑块) / 电话 / 消息 / 盾牌认证 / 日历 / 图表 / 文档 / 审批勾 / 定位 / 指南针(方案) 等，形状圆润有设计感，非简陋线框。
  • ③ 查询功能真实可交互：客户页顶部搜索框可实时过滤（姓名/手机号/企业/信用代码）；下方筛选 chips（全部/待跟进/已成交/公海/待审批）；「筛选」按钮弹出多维条件抽屉（姓名/手机号/企业名/统一信用代码/成交时间）。
  • ④ 交互生效：TabBar 切换、搜索过滤、chip 切换、筛选抽屉、点客户行弹出详情 sheet（跟进记录时间轴 + 分配扭转历史 + 查看档案/跟进/释放回公海 三个动作）全部可点。
  • ⑤ 补齐你此前痛点：客户列表有数据不空白；详情含「上次跟进内容 + 跟进历史 + 分配扭转历史」；顾问可对本人客户做释放/跟进/查看档案；审批页仅显示「提交人+事项+状态+时间」，零单号（D68 红线）。
  • ⑥ 小程序 / H5 同源：两端框架一致，H5 仅多一层浏览器外壳、宽屏限宽，便于在微信外分享访问。
