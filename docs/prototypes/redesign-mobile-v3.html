v3 详细原型改了什么（请逐项审核）
  • ① 分角色菜单：四类角色 TabBar 与首页完全不同 —— 顾问：首页/客户/工单/方案/我的；部门经理：首页/团队/审批/工单/我的；渠道：首页/线索/客户/产品/我的；老板：首页/经营/审批/客户/我的。
  • ② 详细页面（非框架）：每角色首页含角色化指标卡 + 待办/列表 + 快捷入口；客户/团队/线索/产品/经营/审批均给到真实内容页。
  • ③ 同风格登录页：墨蓝+香槟金，企融通 Logo、slogan「企业融资顾问服务平台」、密码/验证码双登录态、记住我/忘记密码，与 app 完全一致。
  • ④ 消息通知（保留并强化）：页头铃铛带未读红点，点开「消息中心」面板；「我的」内独立「消息通知」入口；通知仅显示 提交人+事项+时间（零单号）。
  • ⑤ 查询 & 详情（沿用 v2 可交互）：客户页实时搜索（姓名/手机/企业/信用代码）+ 筛选 chips + 高级筛选抽屉；点客户行弹详情 sheet（跟进内容 + 历史 + 分配扭转 + 三动作）。
  • ⑥ 审批零单号（D68 红线）：所有审批仅「提交人+事项+状态+时间」，无 papr/线索/工单编号。
  • ⑦ 小程序 / H5 同源：两端同一套组件，H5 多浏览器外壳，便于微信外访问。
