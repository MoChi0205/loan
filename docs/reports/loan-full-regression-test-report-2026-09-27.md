## 4. 历史日志中的失败项

1. `aes.key` / `jwt.secret` 占位配置缺失导致启动失败：配置必须继续从所选 Nacos 获取，禁止新增本地默认值。
2. 文件上传写入 `/app` 报只读文件系统：OSS/COS 应按 Nacos 配置启用；测试环境不能静默回退到不可写本地路径。
3. `t_client_follow_record` COUNT 1.269s：需要只读 EXPLAIN，并检查 `staff_code/dept_code/next_follow_at` 组合索引或改写 JOIN。
4. 网关拒绝后重复写响应告警：需要运行态复现并保证过滤器在响应已提交时直接返回，不再写第二次。
