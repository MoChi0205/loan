# loan-main 知识库

> **沟通纪律（用户明确要求）**：每次小程序 / Web / 后端沟通与编码修改前，先读取本知识库相关模块文档 + 对应结论沉淀，再开始执行。**禁止跳过阅读直接开发**。

## 使用规则

1. **每次新会话/任务开始前**：先读本 README，确认涉及哪些模块。
2. **进入具体模块前**：读取对应 `NN-模块名.md` 文档 + 涉及的业务结论（C 系列）。
3. **修改代码前**：明确本次影响范围（前端/后端/数据库），逐个核对对应章节的契约与红线。
4. **修改后**：如有新结论/新发现，**反向更新知识库**（追加结论沉淀、追加红线）。

项目工程 skills 的唯一加载路径是 `.workbuddy/skills/`。前后端代码复用、接口查询、并发与幂等、缓存、异常与稳定性、traceId/日志、名称主显等统一执行 `.workbuddy/skills/loan-code-standard/`；`docs/skills/` 已废弃，不再维护重复副本。
