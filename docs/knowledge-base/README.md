# 当前知识库

本目录是系统文档的单一真值入口，只记录当前有效的代码结构、权限、业务规则和接口边界。

## 阅读顺序

| 任务 | 必读文档 |
|---|---|
| 了解工程、端口和模块 | `00-项目结构与代码地图.md` |
| 修改角色、菜单、接口或数据范围 | `01-角色权限模型.md` |
| 修改敏感数据、业务 ID、基础设施 | `02-业务红线与编码规范.md` |
| 修改表、字段或迁移 | `03-数据模型（DB schema 索引）.md` |
| 修改接口或跨端联动 | `04-后端 API 契约.md`、`05-前端工程要点.md` |
| 修改预约、外出、手机号、报告 | `06-当前业务规则.md`、`09-当前业务流程.md` |
| 构建、测试、部署 | `07-沟通-上线-测试-部署清单.md` |
| 修改小程序功能 | `08-小程序角色功能矩阵.md` |
| 修改报告字段或模板 | `06-当前业务规则.md`、`../reports/README.md` |

## 维护规则

1. 文档以当前代码、数据库 schema 和已确认业务规则为依据。
2. 新规则直接更新对应章节，文档始终呈现唯一有效口径。
3. 文档不得写死可通过代码动态取得的数量，也不得把待办写成已实现。
4. 冲突时优先核对权限守卫、服务实现、测试和数据库 schema，再同步文档。
