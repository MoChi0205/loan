# 当前业务流程

## 客户认领 / 分配 / 转移 / 回收

```text
无归属客户（公海）
  -> 员工认领到本人（并发 CAS：归属未变才写入）
  -> 本人客户：重复申请幂等返回
  -> 经理 / 老板 / 超管：直接分配（提交即生效，不生成审批单；经理仅限本团队）
  -> 顾问跨团队转移申请：目标团队负责人初审（TEAM_REVIEW）-> 老板终审（BOSS_REVIEW）
  -> 超期未跟进：两级预警（归属人 + 部门负责人）-> 定时回收（手动回收可覆盖冷却期）
```

分配/回收均有执行锁防并发重复；强制转移目标为本团队在职成员且排除原归属人（D39/D83）。

## 客户经营分析

```text
客户填写资料并授权上传
  -> 按资料类别保存
  -> 配置启用时执行 OCR/AI 提取
  -> 经营事实与风险维度分析
  -> 生成客户经营报告
  -> 员工权限范围内聚合内部匹配与渠道参考
```

客户报告与内部报告使用不同 DTO 和权限入口。客户侧在任何阶段都不得获得银行产品、准入规则、匹配结果或内部业务 ID。

## 预约与服务

```text
客户发起 / 员工代客创建
  -> 预约确认
  -> 到访我司 / 上门拜访 / 视频会议 / 电话咨询
  -> 服务记录与跟进
  -> 客户时间线和工作台统计
```

员工代客创建直接确认。改期或取消必须在开始前至少 5 分钟发起；工作台跳转到名单时必须带入日期、范围和方式筛选。

## 外出

```text
员工提交外出申请
  -> 有权且非本人的审批人审核
  -> 出发打卡（位置 + 必填照片）
  -> 返回打卡（位置 + 必填照片）
  -> 写入活动时间线和统计
```

外出可以不关联客户，只保存两次打卡的单点位置。

## 手机号解锁

```text
页面显示脱敏手机号
  -> 用户点击查看
  -> 校验客户对象权限
  -> 检查角色豁免、当日首次解锁额度或已批准授权
  -> 返回单次明文并写审计
  -> 超限时创建对应层级审批
```
