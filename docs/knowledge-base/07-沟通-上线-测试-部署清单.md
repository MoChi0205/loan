## 本地联调环境（后端不在本地 docker，直连 prd 服务器配置）

> ⚠️ **2026-08-30 结论**：后端**不依赖本地 docker**，通过 `scripts/run-dev-prd.sh` 启动，**直连 prd Nacos 拉配置 + 远程 MySQL/Redis**。服务器（Nacos/MySQL/Redis）常驻已启动，**业务进程 loan-service 需本地启动**（不在服务器 8080 上跑，服务器 8080/80 是 nginx 无上游 → 502）。

| 项 | 值 | 说明 |
|----|-----|------|
| 后端启动 | `bash scripts/run-dev-prd.sh loan-service` | 后台常驻；JDK8 = `jdk1.8.0_202.jdk`；直连 prd Nacos `124.221.150.239:9848`（namespace=prd，不注册服务、关 Dubbo） |
| 后端地址 | `http://localhost:8080/loan` | server.port=8080 + context-path=/loan（Nacos prd 配置下发） |
| prd Nacos | `124.221.150.239:9848` | namespace=prd；账号 nacos/nacos（prd 已改认证） |
| prd MySQL | `110.42.219.5:9306/loan_db` | 远程（账号 erp_user） |
| 远程 Redis | `124.221.116.28:9379` | 网关/服务读鉴权规则 |
| 网关 | 本地联调版 `:8088` → 转发 `127.0.0.1:8080` | 生产改 `lb://loan-service` |
| 启动验证 | `curl http://localhost:8080/loan/api/mini/me` → HTTP 200 + `{"code":0,...}` | 后端启动约 25s |

> **常见卡点**：小程序「无法进入后续页」= 本地 8080 后端未启动（502）。先 `bash scripts/run-dev-prd.sh loan-service` 起后端，再测 me 接口，最后看小程序。
