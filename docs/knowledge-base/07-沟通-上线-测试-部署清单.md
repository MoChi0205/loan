# 测试与部署清单

## 启动前

1. 确认 JVM 显式提供 `-Dnacos.server-addr` 和 `-Dnacos.namespace`。
2. 确认所选命名空间存在 group `loan` 的 `application.properties`。
3. 确认数据库、Redis、COS、JWT、内部令牌、短信和 OCR/AI 配置均来自该配置。
4. 不启动本地 MySQL、Redis、Nacos、OSS 模拟服务或 Docker。

## 回归范围

| 层级 | 必测内容 |
|---|---|
| 后端 | 单元测试、对象权限、角色范围、状态机、幂等与并发 |
| Web | 菜单、按钮、路由参数、表单、深浅主题和生产构建 |
| H5 | 登录验证码、客户流程、请求代理和生产构建 |
| 微信小程序 | 微信一键登录、验证码登录、上传、报告和构建 |
| 数据 | 迁移幂等、索引、慢查询、敏感字段和跨表业务键 |

## 权限验收

- 逐角色验证菜单可见、按钮可用、接口授权和对象数据范围一致。
- 分别验证 `SELF / DEPARTMENT / COMPANY` 合法范围与越权拒绝。
- 验证客户详情、编辑、历史、回放、预约、外出、工单和审批的关联权限。
- 验证手机号额度内解锁、同日重复不扣次、超限审批和审计日志。
