## 本地联调环境（后端不在本地 docker，直连 prd 服务器配置）

> 当前联调环境后端**不依赖本地 Docker**，由 `scripts/service.sh` 构建并启动本地业务进程，连接既有 Nacos / MySQL / Redis。Web 与 uni-app 客户端的开发请求统一经过 8088 网关，再转发至 8080 后端。

| 项 | 值 | 说明 |
|----|-----|------|
| 四端入口 | `bash scripts/service.sh start all` | 后端、网关、Web、uni-app H5；`status/restart/stop` 同一入口 |
| 后端启动 | `bash scripts/service.sh start backend` | JDK 8；连接 Nacos `prd` 命名空间，不注册服务、关闭 Dubbo |
| 后端地址 | `http://localhost:8080/loan` | server.port=8080 + context-path=/loan（Nacos prd 配置下发） |
| prd Nacos | `124.221.150.239:9848` | namespace=prd；账号 nacos/nacos（prd 已改认证） |
| prd MySQL | `110.42.219.5:9306/loan_db` | 远程（账号 erp_user） |
| 远程 Redis | `124.221.116.28:9379` | 网关/服务读鉴权规则 |
| 网关 | 本地联调版 `:8088` → 转发 `127.0.0.1:8080` | 生产改 `lb://loan-service` |
| Web | `http://localhost:5173` | `/loan` 默认代理至 8088 网关 |
| uni-app H5 | `http://localhost:5174` | `/api` 默认代理至 8088 网关并补 `/loan` 前缀 |
| 启动验证 | `bash scripts/service.sh status` | 四端均显示“运行中”；再验证网关公钥与实际登录 |

> **常见卡点**：客户端无法进入后续页时，按 5174 → 8088 → 8080 顺序检查。不要通过把客户端改为直连 8080 来绕过网关。

## 部署步骤

1. 后端部署：mvn package → 上传 jar → java -jar（与 XXL-Job 同一 Nacos 配置）
2. 前端部署：dist/build/mp-weixin 上传微信开发者工具上传 → 提交审核 → 发布
3. H5 部署：dist/build/h5 静态资源上传 CDN（云开发/OSS/COS），配置 HTTPS
