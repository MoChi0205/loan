# 当前业务规则

## 客户、线索与范围

- 公司所有员工都可以拥有本人客户；“我的客户”是统一入口，“我的线索”只表示本人录入或负责的线索。
- 顾问只管理本人已归属客户；经理可以切换本人和本部门；公司级角色可以切换本人、本部门和全公司。
- 公司公海对内部员工可读，编辑前必须认领或分配；团队公海仅对应部门经理可见。
- **认领/分配/转移分级流转**：无归属客户员工可直接认领（CAS 防并发，重复申请幂等）；本人客户不重复生成待审；经理/老板/超管可强制分配（提交即生效，经理仅限本团队、目标排除原归属人）；顾问跨团队转移须走「目标团队负责人初审 + 老板终审」两级审批，未通过前原归属不变（D39/D83）。
- 渠道不进入公司内部客户名单，也不能通过管理端接口读取客户档案。
- 客户/线索即将超期回收前，除通知归属人外，同步通知其部门负责人（两级预警）；经理预警按“接收人 + 类型 + 关联业务”幂等去重，不重复打扰。
- 一批客户可轮转均分给多个目标顾问（批量均衡分配）；批量回收/认领加执行锁，防止并发重复操作同一批。
- 已禁用客户（`status=DISABLED`）由定时任务分批物理删除，删除前追加 DELETE 审计事件；关联业务数据（订单、审批、画像等）保留不级联清理。

## 预约与外出

- 预约方式：客户到访我司、员工上门拜访客户、视频会议、电话咨询。预约可以不关联客户。
- 支持客户发起和员工代客创建；员工代客创建后直接确认，不需要客户或员工再次确认。
- 开始前至少 5 分钟允许改期或取消。
- 外出必须审批，可以不关联客户；禁止审批本人申请。
- 出发和返回均必须打卡，照片必填，只保存打卡单点位置，不保存连续轨迹。
- 审批人按角色和已授权数据范围处理：部门经理只能审批本部门可见申请；老板、超级管理员可审批全公司；运营等管理角色仅能审批权限配置允许且处于自身可见范围内的申请。

## 服务台查询

- 预约、外出、工作台支持日期范围查询；单日是范围相同的快捷场景。
- “包含未完成”用于查看跨工作日仍未完成或逾期的预约、外出、跟进和服务事项，不能把当前日期误当作唯一工作日。
- 从工作台、消息通知或审批中心跳转时，必须保留日期范围、数据范围、客户和业务方式等筛选条件。

## 手机号查看

- 普通页面始终显示 `前三位****后四位`。
- 老板、超级管理员可直接查看原值；其他员工在配置额度内可直接解锁。
- 首次解锁按“员工 + 客户 + 日期”计数；同一员工同日重复查看同一客户不重复扣次，跨日重新计数。
- 顾问/运营超限由本部门经理审批；部门经理超限由老板或超级管理员审批，禁止自审。
- 日额度由 `SENSITIVE_VIEW/daily-limit` 配置，初始为 30；线索和客户统一计数，旧永久授权不能跨日绕过。
- 按员工、客户、日期保留首次解锁审计；每次受控查看另有操作日志，老板/超管也留痕但不受额度限制。
- 原值接口只允许签名令牌中的 Web 端类型；客户端请求头不能改变令牌端类型。明文不写日志、不进入 URL、不由列表接口返回。

## 报告与材料

- 客户报告：经营画像、多维数据分析、风险提示和经营优化建议；不含银行、准入或进件建议。
- 员工内部报告：在权限范围内聚合经营画像、风险分析、现有内部匹配结果和合作渠道参考。
- 客户材料按资料类别上传，OCR/AI 只有在相应配置启用时才执行；无法验证时不得展示“已一致性核验”。
- 固定声明：`本报告仅使用客户主动填写及授权上传材料；未调用外部个人信息查询接口。`
- 初筛生成时锁定当前模板版本，生成客户视角和员工内部视角两套不可变 JSON/HTML 快照，并归档对应 PDF；客户产物不包含银行、产品、准入规则或内部匹配统计。
- 模板后续修改不会改变历史报告；报告产物对象键仅供服务端受控下载，不作为客户端业务字段展示。
- 附件下载（`/api/mini/upload/{fileKey}`）必须登录且校验归属：渠道不可下载，客户仅限本人名下材料，防止未授权越权读取任意附件。

## 开发实现口径

- 当前开发阶段只维护现行代码路径；不保留旧 SQL 注解、旧 Mapper 方法或兼容回退。
- 业务 SQL 使用 MyBatis-Plus Wrapper；SQL 耗时由安全拦截器记录，不输出 SQL 原文或敏感参数。
- 手机号、短信记录和员工联系方式只接受 AES 密文；历史明文必须先由受控迁移程序使用当前 `aes.key` 重加密，迁移前禁止启动业务读取，代码不提供明文回退。
