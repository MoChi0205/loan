# 前端工程要点

## Web

- 工程：`loan-web`，开发端口 9173，代理默认指向 9088 网关。
- 页面导航以独立子路由为准；切换子菜单必须改变路由和实际页面，不在一个页面内伪装成不可定位的子标签。
- 工作台卡片跳转必须携带日期、数据范围和业务筛选条件，目标页读取并回显这些条件。
- 服务台日期筛选统一支持开始日期/结束日期；“包含未完成”用于跨工作日补看逾期或仍待处理事项。
- 菜单由角色授权生成；父模块没有任何可见子菜单时，父模块也不显示。
- 表格、抽屉、下拉框和弹窗同时验证浅色与深色模式，遮罩层不得透出底层内容。

## H5 与微信小程序

- 工程：`loan-mini`；H5 开发端口 9174，小程序通过微信开发者工具运行。
- H5 请求经开发代理访问 9088；微信小程序使用配置的网关地址。
- 小程序以微信一键登录为主，同时支持验证码登录，不提供密码找回。
- 图片验证码允许随机字母和数字输入，不能使用仅数字键盘。
- 客户页面只展示经营分析和服务数据，不展示内部准入、银行或渠道匹配信息。

## 统一交互

1. 页面筛选条件、URL 查询参数和后端参数使用同一语义。
2. 枚举值在页面显示中文名称，不直接显示内部代码。
3. 客户、员工、部门和报告在页面显示名称或可读摘要，不显示内部业务 ID。
4. 手机号默认脱敏；查看原值必须走统一解锁组件并实时刷新剩余额度。
5. 公共表单组件统一处理日期时间、搜索下拉、校验、加载态和重复提交。

## 日期控件尺寸

- 桌面端日期范围选择器最小宽度为 `260px`；服务台顶部范围筛选使用约 `280px`。
- 日期时间范围表单最小宽度为 `320px`，必须完整显示开始值、分隔符和结束值。
- 视口宽度不超过 `760px` 时恢复为容器宽度，不能造成横向滚动或遮挡。
