## 自绘 TabBar（C17，**禁用原生**）

- `pages.json` **移除 tabBar 配置**（uni-app 的 tabBar `custom` 仅微信/抖音支持，H5 忽略 —— 双端割裂）
- `components/TabBar.vue`：根据 `store.isChannel` 角色化渲染 tab 列表
- 切换一律 `uni.reLaunch`，**禁用 `uni.switchTab`**（无原生 tabBar 配置会失败）
- 挂载页面：home / match / report-list / order-list / mine / product-list
- **渠道角色 TabBar = 4 tab（T4）**：首页 / 我的产品 / 录入客户 / 我的。`TabBar.vue` 据 `store.isChannel` 渲染 4 项；`current="client"` 表示「录入客户」页（渠道线索录入入口）。非渠道角色维持 5 tab（home / match / report-list / order-list / mine）
- 每个页面 `.content` 加 `padding-bottom: calc(var(--space-16) + env(safe-area-inset-bottom))`

## easycom（autoscan=false）

- 自动：`^App(.*)` 规则 → `AppButton`/`AppIcon`/`AppTag`/`AppListItem`/`AppStepper`/`AppEmpty`/`AppSkeleton`
- 非 App 前缀组件（如 `TabBar`）需 **显式 import**
- 跨文件复用：`import AppIcon from '@/components/AppIcon.vue'`（注意 `@` 是项目根）

## AppIcon（已扩 16 个）

- 纯 CSS 单色（currentColor），零依赖
- name 列表：match / chart / bolt / lock / list / check / alert / arrow / wechat / **home / mine / bank / order / refresh / workbench / users**
- 默认兜底 `ico-default` 圆点
- ⚠️ **避免空 CSS 规则** `.ico-match { }` —— CSS minifier 会移除，导致 `.ico-match` 类选择器在编译产物中消失（虽然子元素样式仍渲染，但元素本身无属性继承，渲染在 mp-weixin 偶发异常；建议给每个 `.ico-*` 至少一个非空属性）
- ⚠️ **避免 `<view v-if><view v-else-if>...<view v-else>` 长链编译歧义**：mp-weixin 编译产物可能丢失 children。**改用独立 `v-if` 链**（无 v-else）

## H5 hover 态（C18）

```css
@media (hover: hover) {
  button:not([disabled]):not([loading]):hover { opacity: 0.88; }
  .u-hover {
    transition: opacity var(--transition-fast), transform var(--transition-fast), box-shadow var(--transition-fast);
  }
  .u-hover:hover { opacity: 0.88; transform: translateY(-2rpx); box-shadow: var(--shadow-md); }
}
```

- AppButton 自带 hover-class（hover-class="btn-hover"）
- 可点击卡片加 class="u-hover"
- 小程序端媒体查询不命中，零影响

## 无障碍（WCAG）

- 对比度 ≥ AA（4.5:1 文字色用 `-text` 变体）
- 触控目标 ≥ 88rpx（44px）
- 焦点可见：`:focus-visible` 全局样式（金色 outline）
- 键盘可达：AppListItem 自带 role / tabindex / aria-label

## store/user.js 关键状态

- `role`：customer / channel / adviser / deptmgr / boss / operator / super（决定 TabBar + 守卫）
- `authStatus`：UNAUTHED / ENTERPRISE / PERSONAL
- `token`：持久化 key `loan_token`
- `role` 持久化 key `loan_role`
- `me` 接口返回 `roleInfo`（userType + roleCode），刷新以服务端为准

## 响应式基线（T3 · #1 320px 小屏 / 平板走查）

- **字号下限 22rpx**：页面内禁止出现 `< 22rpx` 的字号字面量（18rpx / 20rpx / 21rpx 等折算 320px 屏仅 7.7~9.0px，违反可读性）。
  既有 22rpx / 23rpx 共 22 处（折算 9.4~9.8px，已达下限）维持不动，不二次返工。
- **Token `--fs-xxs: 22rpx`**：App.vue 注入，作为字号下限常量。`--fs-xs` 同为 22rpx（B 类 `.tab-label` 改用 `var(--fs-xs)`）。
- **`u-shell` 限宽机制**（平板 / iPad，判定 `windowWidth > 768`）：
  - JS 驱动：App.vue `onLaunch` 用 `uni.getWindowInfo()`（兼容 `getSystemInfoSync()`）取 `windowWidth`，`store.setTablet(windowWidth > 768)`。
  - `store/user.js`：`isTablet` state（默认 false）+ `setTablet(v)` action。
  - App.vue 全局样式：`.u-shell { max-width: 600px; margin: 0 auto; }`；`.tab-bar.is-tablet { max-width:600px; left:50%; right:auto; transform:translateX(-50%); }`（TabBar 基类 left/right 用 `!important` 覆盖以保证 mp-weixin 生效）。
  - `max-width` 用 **px**（不随 rpx 放大），正是限宽所需。
- **挂载清单**（各 tab 页根节点 `<view>` 加 `:class="{'u-shell': store.isTablet}"`，TabBar 根节点加 `:class="{'is-tablet': store.isTablet}"`）：
  - home / match / report-list / order-list / mine / product-list（6 个 tab 页）+ index 落地页，共 7 个页面根节点。
- **双端方案**：H5 端保留既有 `@media (min-width:768px) uni-page-body{max-width:600px}`（框架元素不易挂 class，双保险）；小程序端靠 `u-shell` / `is-tablet` class 生效（wxss 不支持媒体查询宽屏治理，被 `#ifdef H5` 隔离）。
- **踩坑**：`#ifdef H5` 隔离媒体查询会导致小程序端丢失宽屏治理 → 宽屏 / 窄屏差异化必须走 JS + class，不能依赖 wxss 媒体查询。

## 常用组件 API

| 组件 | 用法 |
|------|------|
| `<AppButton variant="primary\|ghost\|gold\|text" size="sm\|md\|lg" :block="true" :loading :disabled hover-class="btn-hover" @click>` | 按钮（`variant` 为规范命名；`type` 为兼容别名，优先 variant） |
| `<AppIcon name="..." size="sm\|md\|lg" color="#...">` | 图标（16 个 name） |
| `<AppTag type="info\|success\|warning\|danger" size="sm\|md">` | 标签（语义色） |
| `<AppListItem :title :desc :meta @click>` | 列表项（自带无障碍） |
| `<AppStepper :steps :current @change>` | 步骤条 |
| `<AppEmpty title desc>` / `<AppSkeleton>` | 空态 / 加载 |
| `<TabBar current="home\|match\|report\|order\|mine\|product">` | 角色化底部导航 |
