## 真值位置

- 表结构：`db/loan-db-schema.sql` 与按顺序执行的 `db/migration/*.sql`。
- Web 路由与菜单：`loan-web/src/router`、后端组织菜单接口和角色菜单表。
- 小程序页面：`loan-mini/pages.json`、`loan-mini/pages/`。
- 客户对象权限：`client/security/ClientAccessGuard.java`。
- 服务运营范围：`serviceops/service/ServiceOperationScopeService.java`。
- 手机号解锁：`sensitive/service/SensitiveViewService.java`。
- 报告隔离：`report` 与 `mini/controller/MiniMatchController.java`。
