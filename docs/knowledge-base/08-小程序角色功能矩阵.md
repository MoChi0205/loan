# 小程序与 H5 功能矩阵

该矩阵描述客户端现行边界。Web 管理能力不能因接口存在而直接暴露给客户或渠道。

| 功能 | 客户 | 渠道 | 公司员工 |
|---|---|---|---|
| 微信一键登录 | 支持 | 按渠道身份配置 | 支持已绑定身份 |
| 验证码登录 | 支持 | 支持 | 支持 |
| 密码找回 | 不支持 | 不支持 | 不支持 |
| 企业/个人认证 | 支持 | 不支持 | 不支持 |
| 主动填写与上传材料 | 支持 | 不支持 | 可按内部权限协助 |
| 经营分析与客户报告 | 仅本人 | 不支持 | 按客户对象权限查看内部视角 |
| 银行产品与准入规则 | 不展示 | 仅合作产品管理范围 | 仅内部授权范围 |
| 客户名单 | 仅本人资料 | 完全排除 | 按本人/部门/公司范围 |
| 预约 | 可发起、改期、取消 | 不支持 | 可代客创建和管理 |
| 通知 | 本人 | 本人 | 本人 |

## 登录边界

- 微信小程序以 `wx.login` 和微信手机号能力为主；测试环境是否 mock 由 Nacos 开关决定。
- 微信身份与 Web 客户通过手机号对应的客户档案绑定，不建立两套互不关联的客户记录。
- H5 图片验证码支持随机字母与数字；输入组件不得限制为纯数字。
