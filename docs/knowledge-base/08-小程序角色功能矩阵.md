# 小程序与 H5 功能矩阵

该矩阵描述客户端现行边界。Web 管理能力不能因接口存在而直接暴露给客户或渠道。

| 功能 | 客户 | 渠道 | 公司员工 |
|---|---|---|---|
| 微信一键登录 | 支持 | 按渠道身份配置 | 支持已绑定身份 |
| 验证码登录 | 支持 | 支持 | 支持 |
| 密码找回 | 不支持 | 不支持 | 不支持 |
| 企业/个人认证 | 支持 | 不支持 | 不支持 |
| 主动填写与上传材料 | 支持 | 不支持 | 可按内部权限协助 |
| 经营分析与客户报告 | 仅本人 | 不支持 | 按客户对象权限查看内部视角 |
| 银行产品与准入规则 | 不展示 | 仅合作产品管理范围 | 仅内部授权范围 |
| 客户名单 | 仅本人资料 | 完全排除 | 我的客户（本人归属）/ 团队（部门经理，本部门排除本人）/ 公海（公司全员可认领、团队仅本部门）；行内释放/回收按角色展示 |
| 预约 | 可发起、改期、取消 | 不支持 | 可代客创建和管理 |
| 通知 | 本人 | 本人 | 本人 |

## 登录边界

- 微信小程序以 `wx.login` 和微信手机号能力为主；测试环境是否 mock 由 Nacos 开关决定。
- 微信身份与 Web 客户通过手机号对应的客户档案绑定，不建立两套互不关联的客户记录。
- H5 图片验证码支持随机字母与数字；输入组件不得限制为纯数字。

## 员工客户操作边界（D74/D75，2026-09-10 起生效）

- 「我的客户」合并页含三个子页签：我的客户（仅本人归属，不放大团队/全司）、公海（公司公海全员可认领、团队公海仅本部门，15-规则）、我的报告；部门经理另有「团队」子页签（本部门在职成员、排除本人）。
- 释放：归属本人的员工角色（顾问/经理/运营/老板/超管）行内可见，落公司公海 + 冷却期；渠道不可见。
- 回收：仅部门经理（团队页签，落团队公海）；老板/运营/超管回收落公司公海，走 Web 操作。
- 认领/申请分配：员工可见；跨团队转移申请走「目标团队负责人初审 + 老板终审」两级审批（D83）。
