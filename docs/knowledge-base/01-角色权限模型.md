# 角色与权限模型

权限必须同时通过菜单、接口和对象数据范围校验。前端隐藏按钮不是授权依据，后端不得只依赖角色名称放行对象操作。

## 身份与角色

| 身份 | 角色代码 | 用途 |
|---|---|---|
| 客户 | `CUSTOMER` | 客户端经营分析、材料、报告与服务进度 |
| 渠道 | `CHANNEL` | 渠道获客与合作产品管理；排除公司内部客户名单 |
| 员工 | `ADVISER` | 顾问本人业务 |
| 员工 | `DEPT_MANAGER` | 本人业务和本部门管理 |
| 员工 | `BOSS` | 全公司经营管理 |
| 员工 | `OPERATOR` | 全公司运营数据；审批仅限明确授权类型 |
| 员工 | `SUPER_ADMIN` / `SUPER` | 全公司系统管理 |

## 客户对象范围

| 角色 | 可读 | 可写 |
|---|---|---|
| `ADVISER` | 本人客户、公司公海 | 本人客户；公海需先认领或分配 |
| `DEPT_MANAGER` | 本人、本部门归属客户、本部门团队公海、公司公海 | 本人和本部门已归属客户；公海需先认领或分配 |
| `BOSS` / `OPERATOR` / `SUPER_ADMIN` / `SUPER` | 全公司客户 | 全公司客户 |
| `CHANNEL` / `CUSTOMER` / 未知员工角色 | 不可访问管理端客户对象 | 不可访问 |

客户详情、历史和编辑都必须经过对象级守卫；编辑在事务中锁定客户记录，防止校验后归属发生并发变化。

## 服务运营范围

| 角色 | 可选范围 |
|---|---|
| `ADVISER` | 本人 `SELF` |
| `DEPT_MANAGER` | 本人 `SELF`、本部门 `DEPARTMENT` |
| `BOSS` / `OPERATOR` / `SUPER_ADMIN` / `SUPER` | 本人、本部门、全公司 `COMPANY` |

该范围统一作用于预约、外出、每日服务台、回访、工单和客户回放。管理角色仍可选择只看本人数据。

## 审批范围

- “我的申请”只显示本人提交的申请。
- 部门经理处理本部门授权范围内的审批，禁止审批本人申请。
- 老板、超级管理员处理公司级或终审事项。
- 运营仅处理明确配置给运营角色的审批类型，不默认拥有全部审批权。
- 菜单可见、接口权限和审批数据范围必须一致；任一层无权即拒绝。
