# 02 · 业务红线与编码规范

## 用户明示红线（不可破）

| # | 红线 | 后果 |
|---|------|------|
| 1 | **助手不碰 loan-web（Web 管理端）** | 仅做后端 loan-service；前端小程序也是用户授权后才动 |
| 2 | **定时任务必须用 XXL-Job**（已接入），禁止 `@Scheduled` | 避免漏配置导致不执行 |
| 3 | **业务 ID：小写前缀 + 32 位随机** | 工具 `BizIdGenerator.generate("xxx")`；不用主键做查询；需业务唯一索引 |
| 4 | **AES 读取解密需在 Service 手动做** | `@TableField typeHandler` 仅写入生效 |
| 5 | **参考项目（tse）只借鉴范式**，禁止把参考项目自身业务动作（如外呼/拨号）当作本项目需求 | 需求必须独立论证 |
| 6 | **每次沟通先读知识库再改**（2026-08-30 用户明示） | 沟通纪律 |

## 编码规范

### 命名
- 类：PascalCase；接口无 I 前缀（如 `ProductApproval`，不是 `IProductApproval`）
- 方法/字段：camelCase
- 常量：UPPER_SNAKE_CASE
- 包名：小写
- 表名：t_ 前缀 + snake_case（`t_client_screening`、`t_product_approval`）
- 字段名：snake_case（`client_profile_code`、`match_trace_uuid`）

### 业务唯一 ID（强制）
```java
String approvalNo = BizIdGenerator.generate("alloc");   // → "alloc + 32 位随机"
String reportNo   = BizIdGenerator.generate("report");
String orderNo    = BizIdGenerator.generate("order");
```
前缀建议：`report`/`order`/`alloc`/`client`/`product`/`staff`/`bank`/`screening_product`

### 敏感字段
- 手机号 / 统一社会信用代码：写入库前 SHA-256 摘要（`phone_hash` / `credit_code_hash`）
- AES 加密字段：phone / bank_contact.phone 等
- **精确匹配前对入参同样摘要，不以明文比对**

### API 响应
- 统一 `Result<T>`（code=0 成功，code 非 0 失败）+ `ResultCode` 枚举
- 列表用 `PageResult<T>`（page/size/total/records），不要用 MyBatis Page 直接返回

### 代码标准化入口

- 跨端职责、复用与提取、后端单条/批量/组合分页、并发幂等、Caffeine/Redis、锁、统一异常、限流熔断、traceId/日志，以及前端名称主显/编码降级，统一以 `.workbuddy/skills/loan-code-standard/` 为唯一标准。
- 本文只保留红线与入口，不复制标准全文；后端、Web、小程序、网关和 QA 分别从对应 skill 交叉引用并执行验收清单。

### 前端
- **rpx** 单位（750rpx = 屏宽）
- 颜色 / 圆角 / 间距 / 字号 / 阴影 **必须用 App.vue 设计 Token**（`var(--brand-deep)` 等）
- 业务文案**禁用「放款」**（评审决策 08-28），改用「授信额度 / 额度生效时间」

## 沙盒踩坑记录（必读）

| 坑 | 触发 | 解决 |
|------|------|------|
| `npx uni build` ENOENT manifest | manifest 在项目根，uni-build 默认找 src/manifest.json | 用 `npm run build:h5`（内含 `UNI_INPUT_DIR=.`） |
| vite 清 dist 被 safe-delete 拦截（50+ 文件） | `dist/build/h5` 与 `mp-weixin` 累积文件超阈值 | `mv dist/build/{h5,mp-weixin} /tmp/xxx-$(date +%s)`（mv 不触发删除检查） |
| 批量替换脚本 `\b#fff\b` 不匹配 `:#f5f6f8` | `:` 与 `#` 都是非单词字符，`\b` 在两者之间不成立 | 用 `(?<![0-9A-Fa-f])` 前缀断言 |
| 批量替换 `and` 短路把整段清空 | 返回表达式 `A and B`，A 为空时返 A（空串） | 改前先在小样本验证返回值；改前 `cp` 备份到 `/tmp` |
| 截图原 `home.vue` style 清空后无备份 | 上一轮 dist wxss 是唯一恢复源 | 从 `dist/build/mp-weixin/pages/home/home.wxss` 去 data-v + 格式化还原 |
| mp-weixin `PageResult.empty(long,long)` 泛型推断失败 | 传 int | 用 `PageResult.build(page,size,0L,new ArrayList<>())` |
| ArrayList 缺 import | 引用未导入 | 单独 import |
| `BankProduct` 字段名踩坑 | 实际是 `productCode/amountMin/amountMax/rateMin/rateMax`，不是 `bankProductCode/amountRange/rate` | 查实体 + 验证 |
| dev 模式缓存 | 用户跑的是旧 dist | 清 dist 后 `npm run build:mp-weixin` 重建 |
| 原型服务端口 | 沙盒回收导致 8848 停 | `curl -o /dev/null -w "%{http_code}"` 探测，返回 000 即重启 |
| `grep \b#FFF\b` 会误伤 `#FFFFFF` 子串 | `#fff` 是 `#ffffff` 前 4 字符 | `(?<![0-9A-Fa-f])#FFF\b`（先匹配长值，再匹配短值） |
| 范围工具类 `u-hover` 在 page 切换时被原生 tabBar 遮挡 | 移除了原生 tabBar，自绘 TabBar 是 fixed 底部 48+text 高 | 页面 `.content` 加 `calc(var(--space-16) + env(safe-area-inset-bottom))` padding |
| **manifest.json 误加 `appidNote` 注释字段 → 小程序打不开** | uni-app 把 manifest.mp-weixin 原样并入 app.json；微信解析到未知字段 `appidNote` 直接编译失败 | **manifest.json 只放微信官方字段**（appid/setting/usingComponents），注释写 JSON 注释或单独 md；修复后重构建 + 校验 app.json 无未知字段 |
| **project.config.json appid 构建被重置为 touristappid** | uni-app 用项目根 project.config.json 模板生成 dist 产物，不读 manifest.appid | 改**项目根** project.config.json 的 appid（一劳永逸），或每次构建后手动改 dist |
| app.json 必须无未知字段 | 未知字段导致开发者工具编译失败 | 构建后校验：`python json.load` + 白名单字段比对 |
| **app.wxss 含 `*::before` / `*::after` → 编译报错** | 微信小程序 wxss **不支持 `*::before` / `*::after` 全局伪元素**（只支持 `*` 元素选择器）；开发者工具预览页报「编译 wxss 文件错误」，整个页面样式断链（CSS 变量也不生效） | **App.vue 的减动效 `@media` 块只用 `*`，不要加 `*::before, *::after`**（H5 端伪元素动画由父级 transition 间接覆盖） |
| 微信 wxss 不支持 `:root` 选择器 | 同上：`:root` 是 HTML 选择器，小程序没有 | App.vue 全局变量定义用 `page` 选择器（uni-app H5 端 page 会匹配 uni-page 元素） |
| 微信 wxss 不支持的属性 + `!important` 组合 | `animation-iteration-count: 1 !important` 等动画属性 + !important 在某些场景报错 | 减动效块中只保留 `transition-duration` 等高兼容属性 |
| **页面级 `:focus` 伪类 → 编译报错** | 微信 wxss **不支持 `:focus` 伪类**（input 聚焦样式用原生 `focus-class` 机制）；页面上 `input:focus`/`textarea:focus` 触发「编译 wxss 文件错误」 | 页面 .vue 里 `:focus` 规则用 `/* #ifdef H5 */ ... /* #endif */` 隔离（H5 保留聚焦样式，小程序端移除） |
| 微信 wxss 不支持的语法总清单 | `:root` / `*::before` / `*::after` / `:focus` / `:hover` / `@media (prefers-reduced-motion)` / `@media (hover: hover)` / `:not(选择器)` 等 | 全部用 `#ifdef H5` 条件编译隔离（H5 专用能力）；构建后扫描 `@media/:hover/:root/:focus` 确认清零 |
| **`<text>` 嵌套 `<text>` → wxml 编译失败** | Vue 模板中 `<text class="X">文本 <text class="Y">{{v}}</text> 文本</text>` 这种嵌套，Vue 编译器输出 `((!))` 占位符 + wxml 编译报「unexpected character `<`」 | **禁止 `<text>` 嵌套 `<text>`**。要么拆成独立 `<text>`（sibling），要么外层用 `<view>` 包裹（view 内可含 text）；必填 `*` 用 sibling `<text class="req"> *</text>` 表达 |
| wxml 编译失败标记 `((!))` | 出现说明 Vue 模板有未解析表达式或语法错 | 构建后 grep `((!))` 应为 0；非 0 则 Vue 模板必有编译问题 |
| **wxss 用 `*` 通用选择器 → `error at token '*'`** | 微信 wxss **不支持 `*`、`+` 相邻兄弟**（报 error at token '*'）；`.stack > * + *` / `.actions > *` 这种写法编译失败 | 改用微信兼容写法：`.X view, .X button { flex:1 }`（后代+标签选择器，注意 AppButton 根是 `button` 不是 view）或 `view:first-child { margin-top:0 }` |
| **placeholder 含 `{` → wxml `unexpected character`** | wxml 中 `{` 是数据绑定起始符号，placeholder 文本里的 `{` 会被当作表达式解析报错 | placeholder 文案避免 `{`/`"` 特殊字符，改用纯文本描述 |

## 遗留项 T1–T5 业务结论沉淀

| # | 结论 | 来源 |
|---|------|------|
| ① | **响应式必须 JS 驱动**：小程序 wxss 不支持 `@media` 宽屏治理，且被 `#ifdef H5` 隔离；宽屏/平板差异化改走 JS 驱动 class（`store.isTablet` + `u-shell`/`is-tablet`），不能依赖 wxss media query。 | T3 |
| ② | **字号下限 22rpx**：统一用 Token `--fs-xxs`/`--fs-xs`（值 22rpx）；信息密度类 22/23rpx 是否统一提到 24rpx 待设计拍板（不阻塞）。 | T3 |
| ③ | **facts 合并铁律**：OCR 回灌 `SubmissionFactsMerger.mergeFromOcr` 只补空、永不覆盖既有值；回灌写库须 `for update` 行锁防并发覆盖。 | T2 |
| ④ | **基准数据禁硬编码**：行业均值等基准数据统一走 `t_industry_benchmark` + `IndustryBenchmarkService.avgByDimension`，缺失才兜底常量，禁止在业务里硬编码。 | T1 |
| ⑤ | **审批接口权限按 type 差异化**：`MiniRoleGuard.requireApproverFor(type,user)` + `ApprovalService.requireTypeEnabled` 做白名单校验，禁一刀切；当前 `loan.mini.approval.types=ALLOCATION`。 | T5 |
