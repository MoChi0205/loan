# 小程序首页设计规范（墨蓝 · 皇家蓝 · 香槟金 v2）

> 来源：2026-09-10 用户确认「唯一视觉参考 = `docs/prototypes/redesign-role-business-review.html`（内嵌 `redesign-all-roles-v1.html`）」并按 D70 落地。
> 本规范为小程序首页（含 TabBar、我的页头、角色化宫格）的唯一视觉依据，与 `loan-mini/App.vue` 设计令牌严格对齐。
> 2026-09-08 的「冷玻璃 #2443C2」版本已被本版取代。

## 1. 设计目标

- **墨蓝 + 皇家蓝 + 香槟金**：深墨蓝 `#111E36` 做 Hero/深底，皇家蓝 `#2C52C9` 做主交互与选中，香槟金 `#C7A15A` 做强调点缀。
- **暖底 ivory**：页面底 `#FBF8F2`、输入底 `#F3EEE4`、分割线 `#ECE6DA`，替代原冷灰蓝。
- **角色化**：首页按 7 角色差异化（问候头 + 角色胶囊 + 统计行 + 快捷宫格 + 信息卡）。
- **顶部紧凑**：Hero 一行 = 头像 + 问候/姓名 + 消息铃铛；角色胶囊紧随；sub 文案在下。
- **布局稳定**：快捷宫格按磁贴数量分列（**2–4 列，取末行空位最少**的方案，唯一实现 = `loan-mini/utils/grid.js`），不横向滚动、不断层、末行不留空。

## 3. 顶部 Hero（`home.vue` `.m-head`）

- 深墨蓝渐变底 + 右上香槟金光斑（`--hero-gradient`），文字用白色（深底）。
- 结构：`.m-head-user` 一行 = 头像(96rpx 圆角) + 问候列(问候语 + 姓名 + 「授权使用微信头像」) + 消息铃铛(白图标 + 红点)。
- 角色胶囊 `.role-pill`：半透香槟金底 + 细金边 + 香槟金字，内容「角色 · 类型」。
- sub 文案取自 `utils/roles.js` 的 `homeSub`。

## 4. 微信头像（详见 `skills/loan-mini-avatar`）

- MP：`<button open-type="chooseAvatar" @chooseavatar>` 拉起微信头像选择；H5：提示在微信内授权。
- `store.user.avatarUrl`：来自 `/api/mini/me.avatarUrl`；空则首字默认头像（香槟金渐变底）兜底。
- `utils/avatar.js#uploadAvatar` 上传到 `/api/mini/avatar`，未就绪时静默降级本地预览。

## 5. 角色化快捷宫格（按数量分列）

- 容器 `.m-grid`（flex 换行 + `gap: 28rpx` + `margin-bottom: 40rpx`）+ 单元 `.m-qk`（宽度由 `utils/grid.js#gridItemWidth(数量, 28)` 按列数注入，白卡 `--bg-card` + `1rpx` 细边 `--line`）。
- 磁贴尺寸（2026-09-11 起逐项对齐设计真源原型，px→rpx ×2）：`min-height: 188rpx`（94px）、`border-radius: 32rpx`（16px）、`padding: 28rpx 12rpx 24rpx`（14/6/12px）、内 `gap: 18rpx`（9px）、`box-shadow: var(--shadow-tile)`（同原型 `0 5px 15px rgba(17,30,54,.05)`）。
- 列数规则：2–4 列中取「末行空位最少」，并列取更多列 → 2→2、3→3、4→4、5→3、6→3、7→4、8→4。不用 CSS Grid（小程序端支持不一致），沿用 flex 更稳。
- 图标底 `.qk-ic`：**80rpx × 80rpx、圆角 24rpx**（即 40px，与设计真源原型 `.m-qk-ic` 一致），内嵌图标 42rpx（占 52.5%，`AppIcon size="tile"`）；底色取自 `utils/roles.js` 的 `TONE_BG[tone]`（royal/gold/ink/green/blue），字形白色。
- 文案 2~4 字（智能匹配 / 我的报告 / 服务单 / 录入线索 / 录入产品 / 审批中心 …），字号 `22rpx`（`--fs-xxs` 下限）。
- 点击：tab 页 `reLaunch`，非 tab 页 `navigateTo`；**当前端无承载页面的入口不放入 `quick`**（渲染侧 `quickItems` 过滤），不再出现「点了才提示去 Web 管理端」。

## 6. TabBar 统一（`components/TabBar.vue`）

- 角色 tab 结构唯一来源 = `utils/roles.js`（D70 定源、D74 二次合并）：各角色 tab 一律 ≤5，具体条数以该文件各角色的 `tabs` 长度为准（此处不再写死数值，避免漂移）。
- 未选中：中性灰（浅 `#6A768C` / 暗 `rgba(232,237,245,.55)`）；选中：皇家蓝（浅 `#2C52C9` / 暗 `#6E9BE0`）+ 顶部指示条。
- 颜色映射收敛为「中性灰 / 皇家蓝」，**禁止按 tab 跳色**（真实色值注入，SVG 不解析 var()）。

## 7. 禁忌（用户明确反对）

- ❌ 大面积鲜亮电光蓝（`#2C5BFF` 等）作页面主色。
- ❌ 功能图标按角色/语义跳色导致花乱（宫格磁贴统一白字形 + 语义底色）。
- ❌ 快捷宫格用横向 `scroll-view`（数据少时右侧留白、易断层）—— 按数量分列（2–4 列）自动消除末行留白。
- ❌ 顶部 banner 纵向堆叠过高，挤压内容可视区。
