# 小程序首页设计规范（冷玻璃风格 v1）

> 来源：2026-09-08 用户反馈重设计（登录页/首页视觉）。本规范为小程序首页（含 TabBar、我的页头）的唯一视觉依据，与 `loan-mini/App.vue` 设计令牌严格对齐。

## 1. 设计目标

- **冷调低饱和**：主色为冷色调（蓝/青灰），避免鲜亮电光蓝大面积铺底（用户明确反馈「太花、显臃肿」）。
- **磨砂油画 + 毛玻璃质感**：顶部 header 用多层径向渐变光斑模拟油画磨砂感；H5 启用 `backdrop-filter: blur()` 真毛玻璃，小程序降级为静态渐变。
- **明暗对比**：顶部冷玻璃浅底 vs 内容区白卡，形成层级；玻璃底叠加白色高光斑产生光影。
- **顶部紧凑**：header 高度压缩约 40%，头像+问候+认证一行，搜索栏紧跟。
- **布局稳定**：模块固定四列，不横向滚动、不断层、不换行。

## 2. 配色令牌（`App.vue` 的 `page` 块，`--glass-*` 系列）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--glass-bg` | `#E8ECF5` | header 玻璃主底 |
| `--glass-bg-deep` | `#D6DDEB` | 默认头像底、暗部 |
| `--glass-hi` | `rgba(255,255,255,0.45)` | 高光斑 |
| `--glass-edge` | `rgba(255,255,255,0.6)` | 细白边 |
| `--glass-tint` | `#EAF0FF` | 功能图标浅底（统一品牌蓝字形容器） |
| `--glass-gradient` | 多层 radial+linear 渐变 | header 油画光斑底 |
| `--brand-deep` | `#2443C2` | 唯一品牌强调色（选中态/按钮/图标字形） |

> 小程序 `wxss` 不支持 `backdrop-filter`，故 header 用 `--glass-gradient` 静态渐变；H5 端在样式内用 `/* #ifdef H5 */` 叠加 `backdrop-filter: blur(28rpx)` 与半透明底。

## 3. 顶部 header（home.vue `.top-banner`）

- padding：`28rpx 32rpx 32rpx`（原 `48/56rpx` 压缩）。
- 结构：`.user-row` 一行 = 头像(84rpx 圆形玻璃边) + 问候列(姓名+日期) + 认证小胶囊(右侧，`border-radius: 999rpx`)。
- 搜索栏：`72rpx` 白底圆角药丸，紧跟 user-row 下方 `margin-top: 24rpx`。
- 文字：玻璃浅底上用深色 `--text-primary` / `--text-secondary`（**不要**白字，白字仅用于深色 hero）。

## 4. 微信头像（详见 `skills/loan-mini-avatar`）

- `store.user.avatarUrl`：来自 `/api/mini/me.avatarUrl`；空则默认头像兜底。
- 首页头像用 `<button open-type="chooseAvatar" @chooseavatar="onChooseAvatar">` 拉起微信头像选择（仅 `MP-WEIXIN`）。
- 无头像时显示**首字默认头像**（圆形 `--glass-bg-deep` 底 + 姓名首字），不依赖额外图片资源。
- `utils/avatar.js#uploadAvatar` 上传临时文件到 `/api/mini/avatar`，接口未就绪时静默降级为本地临时路径预览。

## 5. 模块网格（固定四列）

- 容器：`.grid-4` / `.nav-grid` = `display:flex; flex-wrap:wrap;` + 白卡底 `border-radius: 24rpx` + `box-shadow`。
- 单元格：`width: 25%`（每格 `padding: 16rpx 4rpx`），超 4 个自动换行且每行完整四列，**无断层**。
- 图标：统一 `--glass-tint` 浅底 + 品牌蓝字形（`AppIcon :color="var(--brand-deep)"`），**禁止按功能跳色**。
- 文案：2~4 字（如「智能匹配」「我的报告」「服务单」「我的」「客户档案」「审批中心」）。

## 6. TabBar 统一（`components/TabBar.vue`）

- 未选中：灰色线框图标（`--text-secondary`）+ 灰色文字。
- 选中：品牌蓝实心图标（`--brand-deep`）+ 品牌蓝文字 + 顶部 6rpx 指示条。
- 图标尺寸：`64rpx`（lg）。
- 颜色映射 `COLOR` 全部收敛为 gray / brand-deep，禁止按 tab 跳色。

## 7. 禁忌（用户明确反对）

- ❌ 首页大面积鲜亮电光蓝（`#2C5BFF` 等）作主色 —— 太花。
- ❌ 功能图标按角色/语义跳色（紫/金/绿/青同时出现）。
- ❌ 数据卡用横向 `scroll-view` —— 数据少时右侧留白、易断层；改为固定四列。
- ❌ 顶部 banner 纵向堆叠过高，挤压内容可视区。
