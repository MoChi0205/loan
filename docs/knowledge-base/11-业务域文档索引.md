## 0.1 怎么读这张表

| 列 | 含义 |
|----|------|
| **业务域** | 业务概念名（`id` 与 JSON 中的 `id` 一一对应） |
| **后端包（实测文件数）** | `包名`(该包下 `.java` 数量)，实测于 `loan-service/src/main/java/com/loan`，共 **46 个包**（含 8 个空包） |
| **前端页面** | mini = 小程序路由（13 条来自 `pages.json`）；web = `loan-web/src/views` 视图目录 |
| **必读文档** | 格式 `NN#章节标题`。`NN` = 知识库文件编号，`章节标题` = 该文件中的**真实标题文本**；机器读版为完整文件名 `NN-xxx.md#章节标题` |
| **相关结论** | `06-业务结论沉淀索引（C1-C19）.md` 中的 C 编号（实际内容覆盖 **C1–C22**） |
| **实现状态** | ✅ 已实现 / ⚠️ **真空包**（真的没有实现）/ 🔀 **位置不一致**（包空但功能已在别处实现） |

### 实现状态三态（关键，别标错）

| 状态 | 判定 | 后果 | 本索引中 |
|------|------|------|---------|
| ✅ 已实现 | 包内或关联包有 `.java` | 直接改 | 30 个域 |
| ⚠️ 真空包 | 全仓零相关类 | 可从零实现，无重复造轮子风险 | 3 个域（`vip` `stats` `crm`） |
| 🔀 位置不一致 | 包目录空，但功能已在别处实现 | **禁止标「无实现」**，标错会导致后续开发重复造轮子 | 6 个域行（`job` `oss` `enums` `interceptor` + `match` 的**两种视角**） |

> **一句话**：索引的目的是告诉人「功能在哪」，不是「包存不存在」。
